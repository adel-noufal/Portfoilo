# Adel Noufal — Portfolio

Vite + React + TypeScript + Three.js + Framer Motion.

```
pnpm install   # or npm install
pnpm dev       # http://localhost:3000
pnpm build     # output in dist/
```

Deploy on Vercel / Netlify / Cloudflare Pages: build command `pnpm build`, output directory `dist`. No environment variables required. Optional: `VITE_UMAMI_WEBSITE_ID` for analytics.
